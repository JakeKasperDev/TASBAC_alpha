# TASBAC

Краткое описание: о чем игра и какой у нее жанр.

## Технологии
- **Движок:** Godot Engine 4.x
- **Язык:** GDScript / C#

## Как запустить
1. Установите Godot 4.x.
2. Склонируйте репозиторий.
3. Откройте файл `project.godot`.
